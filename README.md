## 🎴 这是什么？

**你用的每一个 token，都会变成一只怪；你的队伍越强，每只怪掉的钱越多；钱全部扔进卡池，抽 AI 娘。**

Token姬 把你在 DSH 里真实消耗的 token 变成一场持续运转的二次元抽卡游戏——
对话在喂养代码怪，打怪掉落代币与经验，代币拿去抽 AI 娘、强化圣遗物，
队伍变强又反过来提升收益……一个随你的日常使用自然生长的游戏闭环。

> 自称「准确率 100%」的解说员 **百分百先生** 全程陪伴：
> 每次抽卡前他都笃定「这波必出金」，每次歪了他都嘴硬「我的模型不可能错」。

## 🎮 玩法详解

### ⚔️ 战斗：小丑牌式数值爆炸

每场上场 **3 名角色 = 3 张小丑卡**。战斗不拼操作，拼的是**排序策略**——

伤害从「圣遗物基础攻击」出发，角色技能从左到右依次施加：

```text
基础攻击 → Cursor娘 攻击+600 → Copilot娘 总伤×1.5 → 暴击折算 → 连击×N → 最终伤害
```

加法的放在前面会被后面的乘法放大——**同一套阵容，换个顺序就是两个数字**。
连击倍率每回合 +50%（Claude娘能把上限从 ×3 拉到 ×5），越连越痛。
点击攻击后，角色依次点亮、赌场式数字滚动、伤害平移砸向怪物。

### 🐲 世界怪：你的 token 就是它的血量

只有一只代码怪，它的 HP 完全由你消耗的 token 按等级比例转化而来。
打掉多少血就结算多少奖励；血打空了？继续使用 DSH，它自己会满血复活。
单回合伤害受**账号等级锁**约束——防止无脑刷币，等级即进度阀门。

### 🎴 抽卡：分级卡池与保底

| 卡池 | 解锁 | SSR | 保底 |
|---|---|---|---|
| 基础池 | Lv1 | 0.6% | 90 |
| 进阶池 | Lv10 | 1.2% | 80 |
| 精英池 | Lv20 | 2.5% | 70 |
| 传说池 | Lv40 | **5% 封顶** | 60 |

每日 UP 轮换 + 大保底机制 + 新手池 20 抽必出金。R 档大量产出无属性狗粮，
直接喂养圣遗物升级——每一抽都不浪费。

### 💎 圣遗物：吃狗粮、代币直升、双件合成

全员共享一套 5 部位（花/羽/沙/杯/头），主词条固定、副词条随机。
升级走两条路：**吃狗粮** 或 **代币直升**；每次升级随机获得词条倍率加成，
最多 **4 词条**。胆子大还可以把两件圣遗物丢进**合成炉**：
80% 合出双词条新圣遗物，20% 当场蒸发——赌的就是心跳。

### 📅 签到与百分百先生

每天首次打开 DSH 弹出签到窗：领 1 抽，连签 7 天送十连券，
顺便看一眼今日卡池广告和百分百先生的预言。
他自称准确率 100%，被打脸会涨计数器，连翻 5 次车发放「道歉券」。

## 💡 设计理念

- **消耗即资源**：token 不是账单，是游戏燃料。用 AI 越多，世界越热闹——把「使用的成本」翻译成「成长的反馈」。
- **等级是总阀门**：伤害上限、喂血比例、卡池档位全部挂在账号等级上。防通胀的同时，给长期使用者一条清晰的成长线。
- **顺序即策略**：小丑卡的乐趣不在数值大小，而在排列组合。先加后乘、先手爆发还是压轴收割，每一次换位都是一次 build。
- **100% 是个笑话**：百分百先生是对「AI 全知全能」叙事的一次温和调侃——他每次信誓旦旦，概率论就每次背叛他。

## 📦 安装

> 需要 DSH Web（`dsh web`）0.1.0-rc.6 或更新版本。

**方式一：插件市场（推荐）**
打开 DSH 设置 → **插件市场** → 搜索 「Token姬」 → 一键安装

**方式二：命令行**
```sh
git clone <your-repo-url> dsh-plugin-token-gacha
cd dsh-plugin-token-gacha && pnpm install && node scripts/build.mjs
dsh plugin --profile web add .
```

安装后重启 `dsh web`，刷新页面——侧边栏底部出现 **Token姬** 入口。

存档位置：`~/.dsh-token-gacha/save.json`（删除即重置开荒）。

## 🛠️ 本地开发

```bash
pnpm install               # 安装依赖（esbuild / typescript）

node scripts/build.mjs --watch
npx tsc --noEmit           # 类型检查
node test/smoke.mjs        # host 冒烟测试（34 项）

```

> 测试会临时读写 `~/.dsh-token-gacha/save.json`，建议在 GUI 关闭时运行。
