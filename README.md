## 🎮 玩法详解

### ⚔️ 战斗系统：小丑牌式流水线

每场上场 **3 名角色 = 3 张小丑卡**。战斗不拼操作，拼的是**排序策略**——

伤害从「基础攻击」出发，三名角色的技能**从左到右依次施加**到同一个数值上：

```text
基础攻击 → [左]Cursor娘 攻击+600 → [中]文心娘 攻击×1.4 → [右]Copilot娘 总伤×1.5
       → 暴击折算 → 增伤 → 连击×N → 单回合伤害
```

**为什么顺序重要？** 因为技能分「加法」和「乘法」两种：

- **加法**（如 `攻击+600`）放在**乘法**（如 `总伤×1.5`）之前，会被乘法放大——先加后乘收益更高；
- 反过来先乘后加，那笔加成就白给了。

同一套阵容，换个顺序就是两个数字。这就是小丑牌的 build 乐趣。

**其余规则：**

| 规则 | 数值 |
|---|---|
| 连击倍率 | 每回合 ×1.5，第 N 回合 = 1.5^(N-1)，封顶 ×3 |
| 回合上限 | 20 回合，超时判负（怪物保留） |
| 单回合伤害上限 | **等级 × 5000**（账号等级锁，防无脑刷币） |
| 战斗动画 | 点击攻击后角色依次点亮 → 乘区逐项叠加 → 数字滚动 → 平移砸向怪物扣血 |

### 🐲 世界怪：你的 token 就是它的血量

只有一只代码怪，它没有"只数"，HP 完全由你消耗的 token 实时转化：

```text
每 1 token = (0.01 + 等级 × 0.005) HP     ← 缩水版，随等级回涨
```

- 打掉多少血，当场结算多少奖励（代币 + 经验），**血空了就没得打**
- 继续正常使用 DSH，新 token 会自动给怪物补血
- 等级越高：喂血比例越高、血量越大、单次收益越多

### 🎴 抽卡系统：分级卡池与保底

| 卡池 | 解锁 | SSR | SR | R | SSR 保底 |
|---|---|---|---|---|---|
| 基础池 | Lv1 | 0.6% | 5.1% | 94.3% | 90 抽 |
| 进阶池 | Lv10 | 1.2% | 8% | 90.8% | 80 抽 |
| 精英池 | Lv20 | 2.5% | 10% | 87.5% | 70 抽 |
| 传说池 | Lv40 | **5% 封顶** | 12% | 83% | 60 抽 |

**规则细则：**

- **UP 机制**：每日 0 点轮换一名 UP 角色，SSR 中 50% 概率命中 UP；歪了之后进入大保底，下一次 SSR 必为 UP
- **武器池**：SSR 0.7% / 80 抽保底，与角色池同规则；SR/R 档产出武器养成材料
- **新手池**：SSR 概率 ×10（6%）且 20 抽必出 SSR，独立计数，开荒神器
- **R 档产出**：15% 出 R 角色，85% 产出无属性狗粮——每一抽都不浪费
- **十连分享**：只有十连出 SSR 才会弹出分享卡（附带 SSR 角色立绘）

### 💎 圣遗物系统：共享装备 · 狗粮 · 合成

全员共享一套 **5 部位**圣遗物（花/羽/沙/杯/头），不需要每个角色单独刷：

| 部位 | 主词条（固定） |
|---|---|
| 花 | 固定生命 |
| 羽 | 固定攻击 |
| 沙 | 攻击% / 防御% / 充能% |
| 杯 | 增伤% |
| 头 | 暴击率 / 暴伤 |

**副词条**：初始 1 条，最多 **4 条**；词池为 攻击%/防御%/暴击率/暴伤/增伤/充能，
每次升级随机获得一档随机幅度加成（40% 新增词条 / 60% 升级已有，10% 双倍暴击）。

**升级两条路：**

1. **吃狗粮**：抽卡产出大量无属性狗粮（R 粮 150 经验 / SR 粮 400 经验），直接喂；
   真圣遗物也能当狗粮（100 + 等级×50 经验），已装备的会自动卸下
2. **代币直升**：狗粮用完直接花代币，每级 `50 + 等级×20` 代币

**双件合成炉**：选两件圣遗物合成——
**80%** 合出一件双词条全新圣遗物；**20%** 失败，两件同时消失。赌的就是心跳。

**获取途径**：抽卡各档位掉落 / BOSS 战必掉 / 普通战斗 5% 概率。

### 📅 每日签到与弹窗

## 💡 设计理念

- **消耗即资源**：token 不是账单，是游戏燃料。用 AI 越多，世界越热闹——把「使用的成本」翻译成「成长的反馈」。
- **等级是总阀门**：伤害上限、喂血比例、卡池档位全部挂在账号等级上。防通胀的同时，给长期使用者一条清晰的成长线。
- **顺序即策略**：小丑卡的乐趣不在数值大小，而在排列组合。先加后乘、先手爆发还是压轴收割，每一次换位都是一次 build。
- **100% 是个笑话**：百分百先生是对「AI 全知全能」叙事的一次温和调侃——他每次信誓旦旦，概率论就每次背叛他。
- **包豪斯 × 复古未来**：界面构成遵循包豪斯几何美学（锐角、粗边、硬阴影、三原色），暗色主题切换复古未来霓虹——工具也可以是海报。

## 📦 安装

> 需要 DSH Web（`dsh web`）0.1.0-rc.6 或更新版本。

**方式一：插件市场（推荐）**
打开 DSH 设置 → **插件市场** → 搜索 「Token姬」 → 一键安装

**方式二：命令行**
```sh
git clone <your-repo-url> dsh-plugin-token-gacha
cd dsh-plugin-token-gacha && pnpm install && node scripts/build.mjs
dsh plugin --profile web add .
```

安装后重启 `dsh web`，刷新页面——侧边栏底部出现 **Token姬** 入口。

存档位置：`~/.dsh-token-gacha/save.json`（删除即重置开荒）。
