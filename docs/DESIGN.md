# Token姬 · 抽卡计划 — 游戏设计文档（一页速览）

> ⚠️ **本文件已由 `docs/策划案.md`（完整版策划案）取代**，这里保留为一页速览。实现一律以策划案为准。
> 一个把「DSH 使用量」变成「代币」、把「代币」变成「抽卡/养成」、把「养成」变回「更多代币」的 DSH 侧边栏插件。
> 主题梗：百分百正确的 AI 撞上随机概率 —— 打脸喜剧 × 抽卡多巴胺。
> 项目代号：`token-gacha`（插件包名 `dsh-plugin-token-gacha`）

---

## 1. 一句话卖点

**你用的每一个 token，都会变成一只怪；你的队伍越强，每只怪掉的钱越多；钱全部扔进卡池，抽 AI 娘。**

## 2. 核心循环（闭环）

```
使用 DSH（消耗 token）
  → 每累计 5,000 token 生成 1 只「代码怪」（侧边栏可见，上限 30 只）
  → 进战斗（小丑牌式倍率叠加）击杀怪物
  → 掉落代币（与队伍 DPS 成正比）+ 小概率圣遗物
  → 代币抽卡：角色池（SSR AI 娘）/ 武器池（专武），圣遗物也是抽卡掉落物
  → 养成：命座（重复角色）/ 精炼（重复武器）/ 圣遗物强化（狗粮互吃）
  → 队伍 DPS ↑ → token→代币 换算比率 ↑ → 更强的正反馈
```

## 3. 经济系统（关键设计：防通胀）

### 3.1 代币来源：打怪

| 项 | 数值（可调） |
|---|---|
| 怪物生成 | 每累计 5,000 token 生成 1 只，队列上限 30 只 |
| 溢出处理 | 队列满时，超出部分按「当前换算率 × 基准掉落」直接折算代币到账（不浪费玩家消耗） |
| 怪物等级 | 默认推荐等级 = 让当前队伍约 5~15 回合击杀的等级；可手动选低等级速刷（掉落少） |
| 基础掉落 | 代币 = 怪物等级 × 等级基数（如 等级×10） |
| **DPS 换算系数** | `掉落系数 = 1 + log₁₀(DPS / 1,000)`，上限 ×5。DPS 每 ×10，系数 +1。**对数曲线，强化有收益但不会滚雪球失控** |
| BOSS | 每 50 只怪出 1 只 BOSS，必掉 1 件圣遗物 + 大量代币 |
| 未击杀 | 不打怪 = 没有掉落；退出战斗怪物保留（这是刷的动力） |

### 3.2 代币消耗（通胀回收，必须有）

| 项 | 数值 |
|---|---|
| 抽卡 | 单抽 160 代币，十连 1600（原神梗） |
| 圣遗物强化 | 每级 `50 + 等级×20` 代币 + 狗粮 |
| 武器升级 / 精炼 | 按等级递增消耗 |
| 每日重置？ | 不做强制重置，靠消耗项自然回收 |

## 4. 抽卡系统

### 4.1 角色池（原神公式）

- SSR 0.6%（up 角色占 50%），SR 5.1%，R 94.3%
- 90 抽小保底必 SSR，180 抽大保底必 up
- 新手池：前 20 抽 SSR 概率 ×10，必得 1 个 SSR
- **每日卡池轮换**（每 24h）：1 个 SSR up + 对应专武 up，其他 SSR 概率降低

### 4.2 武器池

- SSR 武器 0.7%，80 抽保底
- 专武：每个 SSR 角色 1 把，武器池单独计数保底

### 4.3 圣遗物掉落

- 抽卡大概率出圣遗物（含狗粮），小概率出角色 —— 圣遗物是「货币回收 + 养成材料」双重角色

## 5. 角色系统（AI 娘）

### 5.1 首批角色（6 个，机制按 AI 性格梗设计）

| 角色 | 稀有度 | 机制梗 |
|---|---|---|
| DeepSeek娘 | SSR | 「深度思考」：暴击时总倍率额外 ×1.5 |
| GPT娘 | SSR | 「满血输出」：基础倍率全游戏最高，但 5% 概率「卡顿」跳过一回合（摸鱼梗） |
| Claude娘 | SSR | 「写作大师」：连击倍率上限更高（×3 封顶变 ×5） |
| Gemini娘 | SSR | 「多模态」：全队增伤光环 +10% |
| Kimi娘 | SSR | 「长文本」：每回合伤害递增 10%（越聊越强） |
| 豆包娘 | SR | 「免费」：初始必送，数值平平但养成消耗减半 |

### 5.2 属性与命座

- 属性维度（简化 4 维）：攻击力 / 暴击率 / 暴伤 / 增伤，全队乘区
- 命座 0~6：重复角色 +1 命；每命 +12% 基础倍率；2 / 4 / 6 命解锁机制强化
- 专武精炼 1~5 阶：每阶 +8% 增伤
- 队伍：4 人上阵，其余进图鉴待机

## 6. 圣遗物系统（原神规则简化）

| 部位 | 主词条（固定） |
|---|---|
| 花 | 固定生命 |
| 羽 | 固定攻击 |
| 沙 | 攻击% / 防御% / 充能% |
| 杯 | 增伤%（攻击/暴击/暴伤等分型） |
| 头 | 暴击率 / 暴伤 |

- 副词条池：攻击%、防御%、暴击率、暴伤、增伤、充能
- 初始 1 词条，上限 3 词条；每强化 4 级，随机升级已有词条 或 新增词条（原神规则）
- 等级 0~20，主词条随等级成长
- 强化消耗：狗粮（其他圣遗物，经验 = 狗粮等级对应经验）+ 代币

## 7. 战斗系统（小丑牌式纯数值爆炸）

- 自动回合制。每回合 4 个角色依次结算
- 每个角色伤害算式**逐项展开**，倍率一张张叠上去，数字滚动变大：

```
基础 1,024 × 圣遗物 ×2.4 × 命座 ×1.24 × 武器 ×1.16 × 连击 ×1.5 = 30,720
```

- 连击倍率：战斗中每回合 +50%（Balatro 的 xMult），怪物死亡重置
- 怪物 HP 条；击杀 → 掉落动画（代币飞入钱包 + 圣遗物闪光）
- 加速 ×2 / ×4 / 一键跳过
- 打不过 → 回去养成，刷的是「看着数字越变越大」的爽感

## 8. 氛围层：百分百先生（话题度来源）

- 所有随机结果由「百分百先生」解说（AI 嘴替人格）：
  - 抽卡前：「这波必出金，我的算法 100% 确定」
  - 歪了：「这不科学……」「我的模型不可能错，是这个世界错了」
  - 强化前：「防御主词条，稳了」
- **打脸计数器**：本地统计「AI 自称准确率 100%」与实际打脸次数
- **AI 道歉券**：连续打脸 N 次后发放，做成梗图（致敬茶百道道歉券）
- 每个抽卡/强化/战斗结算可生成**分享卡片**（canvas 截图 PNG）：角色立绘 + 数值 + 百分百先生语录 + 打脸计数 → 下载后发抖音/小红书

## 9. 技术架构（已验证 DSH 插件机制）

```
dsh-plugin-token-gacha
├── package.json          # dsh.bundle.patch → cordis.patch.yml；dsh.client manifest
├── cordis.patch.yml      # insert 一行 host 插件：token 监听 + HTTP 路由 + 存档
├── lib/index.js          # host 端（Cordis 插件）
├── lib/client.js         # 浏览器端打包产物（React 面板，ModuleLoader 加载）
├── src/                  # 开发源码（client.tsx / host.ts / game-core.ts 纯逻辑）
└── assets/               # Q 版立绘（MVP 用 emoji+CSS，后续 art 生成 PNG）
```

### 9.1 Host 端（服务端权威，防作弊 + 存档持久）

- **token 计量**：`ctx.inject(["sessionProjections"])` 订阅 `tokenUsage` 投影单元（已确认 API：`ctx.tokenMeter` 注册了 tokenUsage / contextPressure / contextBreakdown 三个投影单元，挂 `session/event` 事件），增量累计 token 消耗
- **存档**：`~/.dsh-token-gacha/save.json` —— 端口无关（localStorage 会随 DSH 随机端口重置，必须 host 端存档）
- **HTTP 路由**（同源，参照 wallpaper-engine 的 `/wallpaper-engine/settings` 模式）：
  - `GET /token-gacha/state`（代币/怪物/背包/卡池状态）
  - `POST /token-gacha/pull`（抽卡，host 决定随机结果）
  - `POST /token-gacha/enhance`（圣遗物强化）
  - `POST /token-gacha/battle`（战斗结算）
  - `GET /token-gacha/card`（分享卡数据）
- 所有随机逻辑（抽卡、词条加点）在 host 端执行，客户端只渲染

### 9.2 Client 端（侧边栏面板）

- `window.__ModuleLoader__.load({ id, factory })` 加载 React 组件（可 `require("react")` / `require("react-dom")`）
- 通过 slot 系统注入侧边栏入口 + 独立面板（slot 名实现时确认，参照 ui-sidebar / ui-slots）
- 面板 Tab：**首页**（代币/怪物/战斗）· **抽卡** · **背包/强化** · **图鉴** · **分享**
- 特效（出金流星、数字爆炸）纯 CSS/Canvas，零外部依赖

### 9.3 构建与安装

- 开发：esbuild 打包 `lib/client.js`（参照 wallpaper-engine 的 `scripts/build-client.mjs`）
- 安装：`dsh plugin --profile web add <本仓库路径>` → pnpm 装进 profile → `dsh.bundle` 自动进 layers
- 本机 GUI 固定跑在 `http://127.0.0.1:3080`，重打包 client.js 后刷新页面即生效

## 11. 红线（合规）

- 只用虚拟代币，零真实货币、零真实彩票
- 界面明示「仅供娱乐，概率为虚拟模拟」
- 不加氪金/充值入口；彩蛋：连续失败 100 次后百分百先生说「别赌了，去写代码吧」
